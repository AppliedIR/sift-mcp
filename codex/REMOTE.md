## Codex on the examiner's machine

This Codex runs on the examiner's own machine, not on the SIFT box.

- The evidence and the case are on the SIFT box: reach them through the MCP
  tools. This machine's shell can't see them.
- Your shell commands here aren't in the case audit; only the MCP tool calls,
  which run on the SIFT box, are.
- There are no managed Codex settings here: the examiner can switch these
  settings off, so they aren't a control.
